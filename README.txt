NETWISE — Computer Networks Study Hub

HOW TO USE
1. Extract the ZIP folder.
2. Open index.html in Chrome, Edge, or Firefox.
3. Use the left navigation to switch between Overview, Unit 1, Unit 2, All Topics, and Completed.
4. Search topics using the search box or press /.
5. Open a topic, then use Mark complete and Bookmark. Progress is saved in this browser on this device.
6. Toggle light/dark theme with the moon/sun button.

IMPORTANT COVERAGE NOTE
The dashboard lists the syllabus topics. The Shortest Path Routing page (Topic 7) is listed but has not yet been generated as a standalone HTML note page in this package. The other included pages are placed in their unit folders. Some original PPT diagrams still need a visual-by-visual verification pass.

This is a local, static website. No installation, server, account, or internet connection is needed after download.
