2. What does the network layer provide?

Core idea: The network layer provides services to the transport layer through the network-layer/transport-layer interface. The transport layer uses these services to communicate with a destination host across an interconnected network.

The network layer handles the movement of packets across networks. The transport layer is concerned with communication between application processes and relies on the network layer to carry data between hosts.

Figure 1: Conceptual view of the service boundary. The network layer transports data across the network; the transport layer should not need to understand the internal router arrangement.

Why does the interface matter?

  • It defines what the network layer offers to the transport layer.
  • It separates transport-layer logic from the network's internal implementation.
  • It provides a consistent way for the transport layer to address destinations.

3. Three design goals listed in the PPT

🎯 Goal 1: Technology independence

Statement: Services should be independent of router technology.

Meaning: The service offered upward should not change merely because the underlying routers or network equipment use a different technology.

Exam keyword: Independent of router technology.

🛡️ Goal 2: Hide internal topology

Statement: The transport layer should be shielded from the number, type and topology of routers present.

Meaning: The transport layer should not have to know how many routers exist, what kinds they are, or how they are interconnected.

Exam keyword: Shielded from router details.

🔢 Goal 3: Uniform addressing

Statement: Network addresses made available to the transport layer should use a uniform numbering plan, even across LANs and WANs.

Meaning: Addressing should remain consistent when communication crosses different kinds of networks.

Exam keyword: Uniform numbering plan across LANs and WANs.

Comparison table for revision

4. Memory diagram: the three goals

Recall mnemonic: TTU — Technology independent, hide router Topology/details, Uniform addressing.

5. Simple example to understand the goals

Suppose a transport-layer process sends data from a host on one LAN to a host reachable through a WAN and another LAN.

  1. Technology independence: The network may contain routers or links built using different technologies. The transport layer should use the network service rather than depend on each device's implementation.
  2. Hide topology: The transport layer should not need to know whether the path crosses two routers or ten routers, or how those routers are connected.
  3. Uniform addressing: The destination should be represented using a consistent network-addressing plan, even when the route crosses LANs and WANs.
Scope note: This is an illustrative example of the three stated goals. It is not a specific scenario quoted from the lecture slide.

6. Exam-ready answers

3 MARKS

Q1. What is meant by services provided to the Transport Layer?

The network layer provides services to the transport layer through the network-layer/transport-layer interface. These services allow the transport layer to use network communication without depending on the internal implementation of the routers and links.

5 MARKS

Q2. State and explain the design goals for services provided by the network layer to the transport layer.

The services provided by the network layer to the transport layer should be designed with the following goals:

  1. Independence from router technology: The service should not depend on the technology used by the routers.
  2. Shielding from router details: The transport layer should be shielded from the number, type and topology of routers in the network.
  3. Uniform addressing: Network addresses made available to the transport layer should follow a uniform numbering plan across LANs and WANs.

These goals provide a consistent service interface and separate transport-layer operation from the internal details of the network.

5 MARKS

Q3. Why should the network layer hide router technology and topology from the transport layer?

The transport layer should use the service provided by the network layer rather than depend on the network's internal implementation. Hiding router technology and topology means that changes in router type, router count or network arrangement do not need to be exposed to the transport layer. This preserves separation between layers and makes the service interface more consistent.

7. Possible questions with answers

These are practice questions derived from the slide's stated content, not verified past-paper questions.

SHORTQ1. Name the interface through which the network layer provides services to the transport layer.

Answer

The network-layer/transport-layer interface.

PRACTICEQ2. List the three design goals for network-layer services.

Answer
  1. Services should be independent of router technology.
  2. The transport layer should be shielded from the number, type and topology of routers.
  3. Network addresses should use a uniform numbering plan across LANs and WANs.

PRACTICEQ3. What does it mean for a network service to be independent of router technology?

Answer

The service offered to the transport layer should not depend on the particular technology used to implement routers.

PRACTICEQ4. What router details should be hidden from the transport layer?

Answer

The number, type and topology of routers present in the network.

PRACTICEQ5. Why is a uniform numbering plan required across LANs and WANs?

Answer

A uniform numbering plan gives the transport layer a consistent network-addressing scheme across different kinds of networks, instead of requiring it to handle incompatible addressing plans for each network type.

PRACTICEQ6. Explain the importance of the network-layer/transport-layer interface.

Answer

It defines the services the network layer offers to the transport layer. A carefully designed interface allows transport-layer operation to remain independent of router technology and internal topology while using a consistent addressing plan.

PRACTICEQ7. A network path changes from three routers to six routers. Which design goal says the transport layer should be shielded from this detail?

Answer

The goal that the transport layer should be shielded from the number, type and topology of routers present.
