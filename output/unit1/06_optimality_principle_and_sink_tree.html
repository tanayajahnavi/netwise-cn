2. The Optimality Principle

Definition: If router J is on an optimal path from router I to router K, then the optimal path from J to K is also part of that same optimal path.

In simpler words: every subpath of an optimal path must itself be optimal for the same endpoints. Otherwise, replacing that subpath with a better one would create a better route overall, contradicting the claim that the original route was optimal.

Conceptual diagram: the route is split at an intermediate router J.

Reasoning step by step

  1. Suppose the route I → J → K is an optimal route from I to K.
  2. Assume, for contradiction, that the subpath J → K is not optimal.
  3. Then another route from J to K would have a lower cost.
  4. Replace the original J → K part with that lower-cost route.
  5. The resulting I-to-K route would have lower total cost, contradicting the assumption that the original route was optimal.
  6. Therefore, J → K must itself be optimal.
Key phrase for exams: “An optimal path contains only optimal subpaths.”

3. What is a sink tree?

Definition: For a particular destination, a sink tree is a tree of optimal routes from every reachable router to that destination. The destination is the root of the tree, and each router's route leads toward it.

It is called a sink tree because packets from different routers are directed toward one common destination. It is a representation of the best routes to that destination, not a separate tree for every source.

Illustrative sink tree. Arrows show the direction packets travel toward destination K.

Important properties

  • One destination: the tree is built for a chosen destination.
  • Routes are optimal: each path represented should be optimal under the chosen cost metric.
  • Subpath consistency: the Optimality Principle explains why routes can share optimal subpaths.
  • Loop-free tree structure: a tree has no cycles, so the selected paths toward the root do not loop.
  • Changes over time: link failures or changed link costs can alter the optimal routes and therefore the sink tree.
Do not confuse: A sink tree is not the same thing as a physical tree-shaped network. The actual network may contain many extra links; the sink tree selects routes from that network for one destination.

5. Why does the principle matter in routing?

🧭 Route consistency

Optimal routes can share subpaths without contradicting one another.

🌳 Sink-tree construction

For one destination, optimal paths can be represented as a tree directed toward that destination.

🧮 Shortest-path algorithms

The idea supports reasoning about shortest paths and is useful background for algorithms such as Dijkstra's algorithm.

Connection to the next topic: Shortest Path Routing gives a practical method for finding minimum-cost routes in a graph. The Optimality Principle explains an important property that these routes must satisfy.

7. Practice questions

These are practice prompts based on the syllabus topic and standard concept explanation, not claims of exact past-paper wording.

Q1. State the Optimality Principle in one sentence.

Every subpath of an optimal path is itself an optimal path between the endpoints of that subpath.

Q2. Why must a subpath of an optimal route also be optimal?

If a lower-cost subpath existed, replacing the original subpath would lower the total route cost, contradicting the original route's optimality.

Q3. What is a sink tree?

A tree representing the selected optimal routes from reachable routers toward one fixed destination, which is the root.

Q4. Does a sink tree mean the physical network itself has no cycles?

No. The physical network can have cycles and extra links. The sink tree is a selected set of routes within that network.

Q5. What may cause a sink tree to change?

Changes to link costs, link failures, or changes in network topology can change which routes are optimal.

Q6. How is this concept connected to shortest-path routing?

It gives a property of optimal routes that shortest-path algorithms aim to find; the next topic explains a method for calculating such routes.

⚡ One-minute revision

  • Optimality Principle: every subpath of an optimal path is optimal.

  • Proof idea: a better subpath would create a better full path, contradiction.
  • Sink tree: optimal routes from routers toward one destination.
  • The destination is the root; arrows point toward it.

  • Link-cost/topology changes can alter optimal routes and the sink tree.

Self-check 🧠

1. What is the central property of an optimal path?

All its subpaths are optimal.

2. What is the root of a sink tree?

The chosen destination.

3. Is a sink tree built for every destination at once?

Usually the concept is defined for one fixed destination; a different destination can have a different sink tree.
