2. What is connectionless service?

Definition: In a connectionless network service, each packet is treated independently and routed toward its destination without establishing a connection in advance. Such packets are called datagrams, and the network is called a datagram network.

Think of sending several postcards to the same address. Each postcard carries the destination information and can be routed independently. They may take different routes and may not arrive in the same order.

📨 No setup phase

The sender can inject a packet into the network without first establishing a virtual circuit.

🧭 Independent routing

Routers make forwarding decisions for packets individually using the destination information and their forwarding tables.

🗺️ Destination in packet

In the Internet Protocol (IP) example from the PPT, each packet carries a destination IP address.

3. How a datagram network works

  1. The source process gives its message to the transport layer, specifying the destination process/host.
  2. The transport layer adds its header and passes the result to the network layer.
  3. If the message is longer than the maximum packet size, the network layer breaks it into packets.
  4. Each packet is sent independently. No advance connection setup is required.
  5. At each router, the destination information is checked against the router's forwarding table.
  6. The router selects an outgoing line/next hop and forwards the packet.
  7. Packets can travel along different paths if routing-table entries or network conditions differ.

4. Router forwarding table

The PPT says every router has an internal table that tells it where to send packets for possible destinations. Each entry is a pair: destination → outgoing line (or next hop).

Important distinction: The table above is a simplified teaching example, not copied from the PPT. The PPT's core point is that each router uses a destination/outgoing-line entry to choose where to forward an arriving packet.

Routing vs. forwarding

  • Forwarding: the local action of sending a packet out through the selected interface/next hop.
  • Routing: the network-layer process/algorithms that determine paths and help build or update forwarding information.

7. Exam-ready answers

3 marksDefine connectionless service.

Connectionless service is a network-layer service in which packets are injected into the network individually and routed independently of one another. No advance connection setup is needed. The packets are called datagrams, and the network is called a datagram network.

5 marksExplain the implementation of connectionless service.

  1. In connectionless service, no connection is established before data transmission.
  2. The source sends packets individually into the network; each packet is called a datagram.
  3. Each datagram carries destination information used by routers to make forwarding decisions.
  4. Every router maintains a forwarding table mapping destinations to outgoing lines or next hops.
  5. Each arriving packet is forwarded independently, so packets from the same message may follow different routes if routing information changes.

8–10 marksExplain datagram routing with a suitable example.

A datagram network implements connectionless service by sending each packet independently without prior connection setup. A message from a source process is passed through the transport layer, which adds its header. The network layer splits a long message into packets if necessary. Each packet is forwarded by routers using destination-based forwarding-table entries.

In the Unit-01 PPT example, a message from process P1 on H1 to P2 on H2 is divided into four packets. Packets 1, 2 and 3 are forwarded from router A through E to F. Packet 4 is instead forwarded from A through B because A has learned of congestion on the A–C–E path and updated its routing table. All packets still target F, but their paths differ.

Thus, datagram networks require no advance setup, route packets independently, and allow forwarding decisions to change as routing information changes. Include a labelled route diagram to complete the answer.

8. Practice question bank

PPT-based The questions below are practice prompts generated from the uploaded slides and the 24CS510 syllabus. They are not claimed to be exact past-paper questions unless explicitly identified as such.

Q1. What is a datagram network?

A network that offers connectionless service in which packets are injected and routed independently, without advance connection setup.

Q2. Why is connectionless service called connectionless?

Because the sender does not establish a connection or virtual circuit before sending packets. Each packet is handled independently.

Q3. What information does a router use to forward a datagram?

The router examines destination information and consults its forwarding table, which maps destinations to outgoing lines or next hops.

Q4. Can packets belonging to the same message take different paths? Explain.

Yes. Each packet is routed independently. If routing information changes, a later packet may be sent along another route. The PPT's packet 4 example illustrates this.

Q5. Explain the PPT's example of packets 1–4.

The network layer divides a long message into four packets. Packets 1–3 travel A–E–F, while packet 4 travels A–B–F because router A updates its routing table after learning of congestion on the A–C–E path.

Q6. Differentiate routing and forwarding.

Forwarding is the local act of sending an arriving packet through the chosen outgoing interface. Routing determines paths and creates or updates the information used for those forwarding decisions.

Q7. Name the Internet protocol example associated with connectionless service in the PPT.

Internet Protocol (IP). The PPT states that each packet carries a destination IP address used by routers to forward packets individually.
