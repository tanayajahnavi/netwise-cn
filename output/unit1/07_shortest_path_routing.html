Shortest Path Routing

Shortest-path routing represents a network as a weighted graph and selects a minimum-cost path from a source router to a destination.

Study note: This page provides a foundational explanation aligned to the syllabus topic. Check your lecturer's PPT for the exact algorithm notation, worked graph, and terminology expected in an exam answer.

1. Network as a graph

Represent routers as vertices (nodes) and communication links as edges. Each edge has a weight representing the cost of using that link. Depending on the network, cost may represent distance, delay, monetary cost, or another routing metric.

2. Core idea

  1. Model the network as a graph with link costs.
  2. Choose a source router and destination.
  3. Compare the total cost of candidate paths by adding the weights of their links.
  4. Select the path with the minimum total cost and use its next hop for forwarding.
Key expression: Path cost = sum of the weights of all edges on that path. The shortest path is the path with the minimum total cost—not necessarily the path with the fewest hops.

3. Why link weights matter

Hop-count metricEvery link may have equal weight, so the route with fewer links is preferred.
Delay metricWeights can represent measured or estimated delay, making a longer-hop route preferable if its total delay is lower.
Capacity or administrative costWeights can encode a network policy or a cost assigned to using a link.
Changing network conditionsIf weights change, the minimum-cost route may change as well.

4. Shortest-path routing vs. flooding

Shortest-path routingFlooding
Selects a route based on link costs and forwarding information.Forwards a received packet over multiple outgoing links, subject to duplicate-control rules.
Aims to send packets along a selected minimum-cost route.Can deliver through multiple paths, but may create substantial duplicate traffic.
Requires usable topology/cost information for route calculation.Does not require the same complete cost-based route calculation.

5. Exam-ready answer structure

  1. Define shortest-path routing.
  2. Explain graph representation: routers as nodes and links as weighted edges.
  3. Describe how path cost is calculated by summing link weights.
  4. Explain that the minimum-cost path determines the route/next hop.
  5. Draw a labelled weighted graph and calculate at least two candidate path costs.
