2. Core idea

📨 Datagram subnet

Connectionless: no advance connection setup. Each packet is routed independently using destination information.

Packet identity: destination address (for example, destination IP address).

🔗 Virtual-circuit subnet

Connection-oriented: a path is established before data packets are sent. Packets carry a virtual-circuit identifier.

Packet identity: VC identifier used with router table state.

Memory line: Datagram = decide the route for each packet. Virtual circuit = establish the path first, then identify packets by their VC.

5. Packet walkthrough: what changes?

Datagram packet

  1. Packet arrives at router.
  2. Router reads destination address.
  3. Router checks forwarding table.
  4. Router chooses outgoing line.
  5. Next packet is routed independently.

Virtual-circuit packet

  1. VC path is established first.
  2. Packet carries a VC identifier.
  3. Router checks its VC table.
  4. Router selects outgoing line and VC identifier.
  5. Packet continues along the established VC.

Important PPT examples

Datagram example: In the PPT, packets 1–3 travel from router A through E to F, while packet 4 is sent through B after A learns of congestion on the A–C–E path and updates its routing table.

Virtual-circuit example: H1 establishes a connection to H2 with identifier 1. H3 later chooses identifier 1 for a separate connection to H2; router A assigns a different outgoing identifier for the second connection.

Exam insight: These two examples make the distinction concrete: datagram forwarding can choose a different route for a later packet; VC forwarding uses connection-specific table mappings and identifiers.

6. Exam-ready answers

3 marksDifferentiate datagram and virtual-circuit subnets.

A datagram subnet is connectionless: no prior setup is required and each packet is routed independently using its destination address. A virtual-circuit subnet is connection-oriented: a path is established before data transfer, and packets carry a VC identifier used with router VC tables.

Conclude that datagram networks route packets independently, while virtual-circuit networks establish a path first and use VC identifiers to forward packets.

8–10 marksCompare virtual-circuit and datagram subnets with diagrams.

Introduction: Network-layer subnets can offer connectionless datagram service or connection-oriented virtual-circuit service.

Datagram subnet: No advance setup is needed. Each packet carries destination information and is routed independently. Routers use destination-to-outgoing-line entries. The PPT's IP example and packet 4 route-change example illustrate this approach.

Virtual-circuit subnet: A path is established before data transfer. Each packet carries a VC identifier. Routers maintain VC table entries and may map an incoming identifier to a different outgoing identifier. The PPT's H1/H3-to-H2 example illustrates identifier mapping.

Comparison: Present a table with setup, packet header, forwarding decisions, route behavior and router state. Draw one diagram for each architecture and conclude with the central distinction: independent packet routing versus a pre-established virtual circuit.

7. Practice question bank

These questions are generated from the syllabus and uploaded PPT; they are practice prompts, not claims of exact past-paper wording.

Q1. What is the main difference between a datagram and a virtual-circuit subnet?

Datagram subnets route each packet independently without advance setup. Virtual-circuit subnets establish a path first and use VC identifiers and router table entries.

Q2. What information is used to forward a datagram?

The destination address is checked against forwarding information that maps destinations to outgoing lines or next hops.

Q3. What does a packet carry in a virtual-circuit subnet?

A virtual-circuit identifier that tells routers which VC the packet belongs to.

Q4. Why can packet 4 use a different path in the PPT's datagram example?

Router A learns of a traffic jam on the A–C–E path and updates its routing table, so packet 4 is forwarded through B.

Q5. Explain the identifier example in the virtual-circuit network.

H1 and H3 each initiate a connection to H2 and may initially choose identifier 1. Router A assigns a different outgoing identifier for the second connection and records the relevant table information.

Q6. Give two benefits or characteristics of each approach.

Datagram: no advance setup and independent forwarding decisions. Virtual circuit: path is established first and packets use VC identifiers/table mappings. Whether either approach is preferable depends on network requirements.

Q7. Why should you avoid saying a virtual-circuit route can never change?

That is too absolute. The established VC defines the route for the connection, but how a network handles failures or route changes depends on its design and may involve re-establishing or updating VC state.

📌 PPT comparison points

Use the lecture comparison dimensions: circuit setup, packet addressing, router state, routing, effect of router failure, quality of service, and congestion control. In a datagram network, setup is not needed, each packet carries the full destination address, routers do not maintain per-connection state, and packets are routed independently. In a virtual-circuit network, setup is required, packets carry a short VC identifier, routers keep per-VC table state, and all packets follow the chosen route. A failed router terminates VCs that pass through it.
